# RF4 Assistant Pro v2.3.10 — привязка водоёма и прокрутка

## Привязка водоёма

OCR иногда не повторяет название локации у отдельной карточки. Теперь
приложение определяет основной водоём снимка по большинству непустых значений
и заполняет им только пустые строки. Явно распознанная локация не меняется.

## Отображение

Карточка водоёма уже содержит весь список предложений. В 2.3.10 список
помещён в вертикальный `ScrollViewer`, поэтому нижние строки доступны при
любой допустимой высоте окна.
