# RF4 Assistant Pro v2.3.15 — обучение на ручной проверке

## Реализовано

После подтверждения окна проверки приложение сравнивает исходную OCR-строку
с итоговым названием. Если пользователь исправил имя, пара сохраняется в
локальный словарь `Cafe/ocr-name-aliases.json`.

При следующих распознаваниях обученный псевдоним проверяется раньше
встроенного словаря, каталога и нечёткого сравнения. Это позволяет исправлять
новые ошибки без выпуска отдельной версии для каждого названия.
