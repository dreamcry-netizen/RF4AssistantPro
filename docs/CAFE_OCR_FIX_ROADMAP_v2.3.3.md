# RF4 Assistant Pro v2.3.3 — дорожная карта исправлений OCR кафе

## Контекст

На реальном снимке кафе присутствуют 10 карточек, но после OCR в окно
проверки попадает только 8 строк. Одновременно у распознанных строк
количество становится неизвестным (`0`), хотя порог веса распознаётся.

Проблема состоит из трёх частей:

1. OCR-блоки PaddleOCR используются как готовые строки, хотя часть результата
   состоит из отдельных слов;
2. два нераспознанных слота молча удаляются;
3. отдельная проверка карточек работает только в Windows OCR fallback-ветке,
   но не после успешного запуска PaddleOCR.

## Этап 0. Воспроизведение и диагностика

- [ ] Сохранить исходный снимок кафе с десятью карточками.
- [ ] Включить подробный OCR-лог через
  `RF4ASSIST_DETAILED_OCR_LOG=1`.
- [ ] Записать для каждого слота индекс, координаты, исходные OCR-блоки,
  распознанное название и причину отбрасывания.
- [x] Проверять результат по инварианту: `10 слотов → 10 строк проверки`.

**Результат этапа:** точно определены два пропавших слота и причина их потери.

## Этап 1. Запретить молчаливую потерю карточек — P0

- [ ] Представить слот кафе отдельной моделью с индексом и исходными строками.
- [x] Не удалять слот, если название не распознано.
- [x] Показывать нераспознанную карточку в окне проверки как пустую строку.
- [x] Добавить подпись вида `Карточка 9: название не распознано`.
- [ ] Добавить предупреждение `Распознано 8 из 10`.
- [x] Разрешить пользователю вручную заполнить пропущенные название,
  количество и вес.

**Критерий готовности:** окно проверки всегда показывает все 10 карточек,
даже если OCR смог заполнить только часть полей.

## Этап 2. Восстановить строки из OCR-блоков — P0

- [ ] Переименовать внутреннюю модель `PaddleOcrLine` или явно разделить
  понятия `OcrWord` и `OcrLine`.
- [x] Сортировать блоки по `CenterY`, затем по `CenterX`.
- [ ] Объединять блоки одной строки по вертикальному пересечению или
  относительному допуску высоты.
- [ ] Сортировать слова внутри строки слева направо.
- [x] Нормализовать пробелы и OCR-ошибки перед разбором полей.
- [x] Поддержать варианты количества:
  `Количество 3 шт`, `Количество / 3 / шт`, `Количество 3`, `3 шт`.

**Критерий готовности:** количество извлекается, даже если PaddleOCR
возвращает `Количество`, `3` и `шт` отдельными блоками.

## Этап 3. Распознавать каждую карточку отдельно — P0

- [x] Использовать известные crop-области десяти карточек для PaddleOCR.
- [x] Распознавать отдельно название, количество и `Масса от`.
- [x] Сохранить приоритет OCR отдельной карточки над общим OCR.
- [x] При неполном общем результате автоматически запускать повторный
  карточный проход.
- [ ] Не считать PaddleOCR успешным только потому, что он вернул хотя бы
  один текстовый блок.

**Критерий готовности:** отсутствие количества или названия в общем OCR
не отключает карточную проверку.

## Этап 4. Нормализация названий рыб — P1

- [ ] Сопоставлять OCR-название с каталогом и его псевдонимами.
- [ ] Исправлять слитные названия:
  `Карасьзолотой → Карась золотой`,
  `Дрейссенаречная → Дрейссена речная`,
  `Карпчешуйчатый → Карп чешуйчатый`.
- [ ] Сравнивать кафе и уловы по каноническому названию или ID рыбы,
  а не по необработанной OCR-строке.
- [ ] Показывать исходную OCR-строку как источник, но сохранять
  нормализованное название.

## Этап 5. Регрессионные тесты

- [ ] Тест на десять слотов при двух нераспознанных названиях.
- [ ] Тест, что нераспознанные слоты не удаляются.
- [ ] Тест на раздельные OCR-блоки `Количество`, `3`, `шт`.
- [ ] Тест на смешанные варианты `г` и `кг`.
- [ ] Тест на слитные названия рыб.
- [ ] Интеграционный тест полного результата кафе с десятью карточками.
- [ ] Проверка, что количество предложений совпадает с числом карточек
  в исходном снимке.

## Definition of Done

Релиз v2.3.3 считается готовым, если:

- в окне проверки отображаются все 10 карточек;
- отсутствующие поля видны пользователю и не теряются;
- количество распознаётся минимум в 9 из 10 карточек на контрольном снимке;
- оставшаяся карточка доступна для ручного ввода;
- ни одна карточка не исчезает без предупреждения;
- автоматические тесты и полный Windows QA завершены;
- исходный архив v2.3.3 доступен для скачивания.
