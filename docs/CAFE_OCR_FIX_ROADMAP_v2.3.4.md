# RF4 Assistant Pro v2.3.4 — прогресс OCR кафе

## Выполнено

- OCR-слова объединяются в строки по вертикальному пересечению и положению центра.
- Слова внутри строки сортируются слева направо.
- Разметка всегда создаёт десять индексированных слотов и сохраняет пустые.
- Подробный лог содержит исходные строки и результат общего/карточного OCR.
- Сохраняется источник распознавания предложения.
- Названия канонизируются по имени и псевдонимам каталога.
- Поддержана компактная форма для слитных OCR-названий.
- В модель записываются ID каталога и исходное OCR-название.
- Добавлены автоматические регрессии компоновки, слотов и канонизации.
