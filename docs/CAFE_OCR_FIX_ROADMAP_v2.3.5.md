# RF4 Assistant Pro v2.3.5 — фокусный OCR названий

На реальном снимке v2.3.4 сохранила все десять карточек и правильно распознала
количество и массу, но пропустила названия «Карась золотой», «Ротан» и
«Густера».

## Реализовано

- отдельный узкий crop зоны названия карточки;
- увеличение crop в четыре раза;
- запуск дополнительного PaddleOCR только при отсутствии имени;
- поддержка строчной первой буквы;
- запись содержимого обеих OCR-попыток в основной журнал при неудаче;
- сохранение ручного ввода для окончательного fallback.

## Следующий контроль

Запустить v2.3.5 на исходном PNG в Windows. Если отдельные названия снова не
распознаны, журнал теперь содержит фактические OCR-строки для точечной
нормализации без предположений.
