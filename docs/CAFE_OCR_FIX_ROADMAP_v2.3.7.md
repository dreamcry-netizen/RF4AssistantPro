# RF4 Assistant Pro v2.3.7 — точечная нормализация названий

## Исправлено

На реальном QA после OCR отображались `Rotan` и `Фустера`. Версия 2.3.7
добавляет встроенные корректировки:

- `Rotan` и визуальный вариант `Potah` → `Ротан`;
- `Фустера`, `Fustera`, `Gustera` и `Ryctepa` → `Густера`;
- `Карасьз золотой` → `Карась золотой`.

Коррекции выполняются до нечёткого поиска по каталогу, поэтому работают и в
старом профиле с неполным каталогом. Исходная OCR-строка сохраняется.

## Следующий контроль

Проверить один снимок кафе в v2.3.7. Ожидаемый результат — отображение
`Ротан` и `Густера` кириллицей без ручного редактирования.
