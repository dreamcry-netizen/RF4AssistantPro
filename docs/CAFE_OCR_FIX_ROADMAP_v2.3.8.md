# RF4 Assistant Pro v2.3.8 — защита на границах UI

OCR может возвращать визуально кириллическое слово с отдельными латинскими
буквами, например `Фyстepa`. В 2.3.8 коррекция применяется к исходному и уже
преобразованному ключу. Кроме распознавателя, нормализация повторяется перед
созданием строки окна проверки и перед сохранением предложения.

Ожидаемый результат: `Rotan` отображается как `Ротан`, а `Фустера` и
`Фyстepa` — как `Густера`.
