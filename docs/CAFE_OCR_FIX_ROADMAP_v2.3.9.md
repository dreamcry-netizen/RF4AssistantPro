# RF4 Assistant Pro v2.3.9 — полный список кафе

## Исправлено

Карточка водоёма ранее намеренно выводила только первые три предложения через
`Take(3)` и показывала счётчик `ещё N`. Ограничение удалено: теперь выводится
весь список последнего снимка кафе.

Если OCR пропустил название водоёма только у отдельных карточек, они
включаются в снимок, когда остальные строки однозначно подтверждают текущую
локацию. Строки с явно другим водоёмом не смешиваются.

## Следующий этап

Для двух пустых названий из второго снимка нужны исходный PNG кафе и
`Screenshots.log`. По таблице проверки невозможно увидеть фактические строки
обычного и контрастного OCR.

## Динамическое число карточек

Кафе может показывать не десять, а восемь или девять карточек, центрируя
неполную нижнюю строку. Внутренняя геометрическая сетка остаётся
десятипозиционной, но в окно проверки передаются только позиции, где общий
или карточный OCR нашёл данные. Пустые позиции не создают фиктивные строки.
Карточка с распознанным количеством или весом сохраняется даже без имени.
