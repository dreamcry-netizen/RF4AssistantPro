  восстанавливаемой транзакцией.
- Добавлена регрессия coordinator; зарегистрировано 107 сценариев.
- Следующий этап: вынести диагностику и screenshot retention.

# v2.3.29 — восстановление садка и коррекция OCR — в проверке

- Исправлена очистка `KeepnetRecords` при применении изображений рыбы.
- Общая замена `ObservableCollection` защищена от ленивой проекции самой
  коллекции.
- Добавлена коррекция `Пескарь обыкновённый` →
  `Пескарь обыкновенный`.
- Добавлены две регрессии; зарегистрировано 106 сценариев.
- Требуется Windows build и повторный QA серии садка: пять рыб должны
  сохраниться, финальный кадр должен дать пять повторов, записи для ручной
  проверки создаваться не должны.
- После исправления продолжаются coordinator импорта, диагностика,
  retention и Windows CI.

# v2.3.28 — применение изображений рыбы — реализовано частично

- Добавлен общий `FishImageResolver` в Core.
- Изображения сопоставляются по нормализованному имени и псевдонимам.
- Поддерживаются локальные `file://`-пути.
- Добавлен регрессионный тест; ожидается 104 автоматических сценария.
- Визуально подготовлено отображение изображения в уловах, карточке и
  садке.
- Windows QA обнаружил регрессию: применение изображений очищало садок.
  Исправление перенесено в v2.3.29.
- Следующий этап: coordinator импорта, диагностика, retention и Windows CI.
